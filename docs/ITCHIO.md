## Title
THE LAST SIGNAL

## Short description (tagline)
A 2D pixel-art radio mystery. Tune three frequencies, uncover what happened at Station 09, and decide how the signal ends.

## Genre / Tags
Adventure, Puzzle, Mystery, Pixel Art, Atmospheric, Singleplayer, Story Rich, Sci-fi, Short, Python

## Description

**August 1997.** Station 09 has been silent for seventeen years. Tonight, someone called it.

You are Alex Reyes, a radio technician sent to find out who. Tune your radio between three frequencies, because each one shows a different version of the station:

- **88.1 MHz - The Present:** what the station looks like now.
- **104.7 MHz - The Past:** what it remembers.
- **121.3 MHz - The Unknown:** what should not be there.

Pick up the **Echo Receiver**, track hidden signals, read the journal, crack the codes, and follow a five-chapter story to one of **two endings**.

### Features
- Five connected chapters, a journal, and two endings
- Three frequencies that change the world, its clues and its puzzles
- Optional code puzzles with digits hidden across rooms and frequencies
- Gold guide arrows and a three-level hint system, so you are never stuck
- Original procedural soundtrack with moods for each room and frequency
- Achievements, three save slots, rebindable keys, and gamepad support
- All graphics and audio are generated by the code. No asset files

### Controls
WASD / arrows move, E interact, SPACE radio, Q change frequency, R Echo Receiver, J journal, K hint, H guide arrows, F flashlight, ESC pause. Xbox-style gamepads work too.

### Install
Download the zip, extract it and run `TheLastSignal.exe`. Windows may warn "Windows protected your PC" because the game is unsigned. Click **More info**, then **Run anyway**. The first launch generates the music in the background (about 20 seconds).
